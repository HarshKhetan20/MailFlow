# VoiceMail AI Agent - Backend API Service

This directory is reserved for the backend server architecture (e.g. Express/Node.js or Python FastAPI).

## Planned Sub-Modules:
- `src/controllers/`: Route handlers for email generation and authentication.
- `src/services/`: OpenAI / Gemini AI API integration, Speech processing backends.
- `src/integrations/`: Gmail OAuth & API handlers.
- `src/middleware/`: Security, rate-limiting, and context validation.
