# VoiceMail AI Agent - Database Layer

This directory is reserved for database schemas, migrations, and ORM configurations (e.g., PostgreSQL / Prisma / Supabase / MongoDB).

## Planned Sub-Modules:
- `migrations/`: Versioned database migration scripts.
- `schema/`: Database tables, user sessions, draft history, and log models.
- `seeders/`: Development database initial seed scripts.
